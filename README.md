# CYBERMINDZ PRO Keyboard Dictionaries

On-demand dictionary files for PRO Keyboard.

English is bundled in the APK. All other language dictionaries are downloaded from here when the user enables a new keyboard layout.

## Download URL format

``nhttps://github.com/CYBERMINDZ/CYBERMINDZ-PRO-Keyboard-Dictionaries/releases/download/v1.0.0/{filename}
``
